See the [Process FBC Fragment workflow for `rhoai-3.7-ea.1`](https://github.com/red-hat-data-services/RHOAI-Build-Config/blob/rhoai-3.7-ea.1/.github/workflows/process-fbc-fragment.yaml) for release workflow context.
